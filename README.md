# KaiStudio

KaiStudio is a Tkinter launcher for the Kai desktop apps:

- Kai Job Finder
- Kai Job Application Tracker
- Kai Recruitment Screener
- Kai Resume Builder Studio

Run it with:

```powershell
python kai_studio.py
```

The window uses `logo.ico` as its app icon and loads the Kai theme from `app_config/theme.json`.
